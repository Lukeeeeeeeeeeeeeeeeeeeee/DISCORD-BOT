## 1. Error Code Format

```
<DOMAIN>-<NUMBER>
```

- **DOMAIN:** 3-8 character abbreviation (uppercase)
- **NUMBER:** 3-digit numeric code

Codes are looked up in dictionaries at `src/lib/aecs/dictionaries/<domain-lowercase>.js`.

## 2. Severity & Impact Scale

| Impact Range | Severity  | Console Output | Telemetry | Special Handling |
|-------------|-----------|---------------|-----------|------------------|
| 0-15       | INFO      | None          | Sent      | Only if `shouldSend` passes threshold |
| 16-45      | WARN      | `console.warn`| Sent      | Subject to suppression |
| 45-70      | ERROR     | `console.error`| Sent     | Subject to suppression |
| 75-90      | FATAL     | `console.error`| Sent     | `vault.forceWriteSync(record)` |
| 90-100     | FATAL     | `console.error`| Sent     | `forceWriteSync` + `process.exit(1)` if `exitOnFatal` enabled |

**Key thresholds:**
- `fatalImpactThreshold` = **90** (set in Dispatcher.js:74) — any impact ≥ 90 triggers FATAL severity
- `webhookImpactThreshold` = **70** (set in Dispatcher.js:85) — errors with impact ≥ 70 are sent to webhook
- `suppressionThreshold` = **50** (set in Dispatcher.js:72) — more than 50 identical errors in a window are suppressed
- `suppressionWindowMs` = **60,000** (60 seconds)

## Escalation Pattern Reference

All escalators receive `(sanitizedMeta, traceContext)` where:
- `sanitizedMeta` — only keys in `safeMetaKeys` survive sanitization
- `traceContext` — `{ traceId, command, userId, guildId, channelId, source }`

**Shared utility for anti-nuke-purge escalation:**
Defined in `src/lib/aecs/sanitize.js` as `getAntinukeEscalation(sanitizedMeta, traceContext)`. Returns `95` when the trace context originates from `anti-nuke-purge` command, triggering FATAL severity. All escalator functions in `db.js`, `cmd.js`, `recruit.js`, `dm.js`, and `economy.js` delegate to this utility as their first check.

**Standard escalator template:**
```javascript
const { getAntinukeEscalation } = require('../sanitize');

escalator: (meta, traceContext) => {
  // 1. Anti-nuke-purge context → 95 (triggers FATAL, threshold=90)
  const an = getAntinukeEscalation(meta, traceContext);
  if (an !== null) return an;
  
  // 2. Check meta-based conditions using defensive null-checking
  if (meta && meta.phase === 'execute.inner') return 72;
  
  // 3. Default returns equal baseImpact
  return 70;
}
```

**FATAL severity is triggered when:** `impact >= fatalImpactThreshold (90)`

**Suppression applies when:** `severity !== 'FATAL'` AND `count > suppressionThreshold (50)` in `suppressionWindowMs (60000)`.
